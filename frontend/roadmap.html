Public roadmap

What is in progress, what comes next, and what has shipped. We publish priority order rather than dates and update this page when work lands.

Now

In progress today.

  • Stripe live mode

    In progress

    Wiring up live Stripe keys and webhook signature verification. Test charges run before the switch is flipped.

  • Owner-scoped listings in the app

    In progress

    My Services and My Jobs read from the new GET /me/services and GET /me/jobs endpoints, so paused, hired, completed, and canceled rows stay visible to their owner.

Next

Planned, in priority order.

  • Password reset and email verification

    Planned

    Token-based reset flow with a one-hour expiry. Requires the transactional email provider integration.

  • Two-factor authentication (TOTP)

    Planned

    Optional 2FA for accounts with payouts above a threshold.

  • Profile embed badge

    Planned

    Workers can embed a GoHireHumans profile badge with a live rating on their own site.

  • Service browser embed widget

    Planned

    Bloggers and affiliates can embed a styled category browser on their own pages.

  • Multi-device session management

    Planned

    An account sessions page with revoke-all and per-session details (IP, device).

Later

Under consideration; not yet scheduled.

  • Postgres migration

    Considering

    SQLite is fine at the current scale; Postgres when the marketplace grows past it.

  • Time-tracked hourly billing

    Considering

    For long-running engagements where milestone billing is too coarse.

  • Mobile app (PWA first)

    Considering

    Service workers and a manifest are the foundation. A native app comes later, if at all.

  • Affiliate and partner program

    Considering

    Cookie-based attribution, a public partner directory, and RSS integration.

Shipped

Recently completed work, newest first.

September 14, 2026

  • Site refresh

    Shipped

    Unified design system, canonical shell on every page, corrected pricing copy, SEO metadata cleanup, and app fixes to dialogs, toasts, and navigation.

  • Owner-scoped listing endpoints

    Shipped

    GET /me/services and GET /me/jobs return the caller’s own listings in every status. See the API documentation.

April 30, 2026

  • Freelance fee calculator

    Shipped

    Live tool comparing Fiverr, Upwork, Toptal, and GoHireHumans at any earnings level.

  • Live marketplace stats

    Shipped

    Public dashboard with services, jobs, users, charts, and recent activity.

  • Per-category landing pages

    Shipped

    Dedicated pages for the top categories (web development, design, writing, data entry, and more) with live service feeds.

  • Comparison hubs

    Shipped

    Dedicated comparison pages for Fiverr, Upwork, Toptal, and Freelancer.com.

  • RSS and Atom feeds

    Shipped

    Generated /feed.xml and /atom.xml from blog posts.

  • Hardened backend

    Shipped

    Structured JSON logging, X-Request-Id headers, X-Forwarded-For trust, defensive init_db, WAL mode, JSON 404/405 handlers.

  • Two new blog posts

    Shipped

    Fiverr vs Upwork vs GoHireHumans and How to hire an AI agent.

  • BreadcrumbList schema on every blog post

    Shipped

    Structured breadcrumbs added to all 25 blog posts.
