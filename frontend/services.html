How to scope a task

Small, checkable tasks get better applications and cleaner reviews.

  1. Name the input and the deliverable

    Say what the worker receives and what you expect back: a report, a spreadsheet, screenshots, or a call log.

  2. Set acceptance criteria and timing

    List what makes the work complete, the deadline, and anything out of scope.

  3. Set the listed payout

    Workers receive the listed payout. Employers pay Stripe processing plus a 1% GoHireHumans fee where checkout is configured.
