For operations teams

A microtask marketplace for business operations.

Post small, bounded tasks that are too specific for generic freelancing and too judgment-heavy for pure automation: quick research, QA checks, data fixes, and admin follow-ups. Start here if your task does not fit one of the named templates.

Good tasks to post

Keep each task to one of these so it can be priced and approved quickly.

  • Quick research: compare three vendors with sources
  • QA checks: test a flow or review a document
  • Data fixes: dedupe, tag, or verify a sheet
  • Admin follow-ups: calls, confirmations, bookings

Why humans help

Where judgment beats automation for this task.

The best marketplace tasks are clear, short, and easy to approve.

A task that takes an afternoon, has one deliverable, and can be checked in ten minutes gets picked up faster, costs less, and is easier to repeat than a vague project.

How to scope it

Four things to include so the first task is easy to approve.

  1. 1

    One clear goal

    Say what the worker is checking and what counts as wrong. One URL, one document, one list.

  2. 2

    Source material or links

    Attach the exact inputs: the page, the file, the transcript, the criteria.

  3. 3

    Deliverable and deadline

    Name the format you want back (table, notes, screenshots) and when you need it.

  4. 4

    An example of acceptable work

    Link a sample deliverable so the worker knows the bar. Keep the first task small so approval is straightforward.
